# Tekirdağ Basketbol İl Temsilciliği

Tekirdağ Basketbol İl Temsilciliği için geliştirilen public frontend uygulaması.

## Yerel geliştirme

```powershell
cd frontend
npm install
npm run dev
```

Uygulama varsayılan olarak `http://localhost:3000` adresinde çalışır.

## Kontroller

```powershell
npm run typecheck
npm run lint
npm run test
npm run build
```

> Proje geliştirme/demo aşamasındadır. Yönetim paneli, backend ve gerçek authentication içermez.
